# v0.1.0 UI MVP

## Status

`Implemented` as the first desktop presentation milestone. This release is a
presentation-first milestone: it makes the application pleasant to open and
establishes the settings contract without pretending that the financial engine
or durable business database already exists.

## Product outcome

The first screen should communicate the Nestworth direction immediately:

- a calm household balance-sheet overview;
- a clear Preview marker wherever the values are not live;
- navigation for Overview, Accounts, Activity, Analytics, and Settings;
- useful Coming Soon states for pages whose domain/application contracts are
  not implemented yet; and
- a Settings page that changes how the application looks and formats values.

The Dashboard values are static demo values. The UI does not open SQLite,
construct SQL, calculate net worth, perform FX conversion, or claim that the
demo values represent the user's finances.

## Implemented surface

### Overview

- Nestworth brand mark and sidebar navigation.
- Net worth hero card with Preview badge, current-total label, demo change, and
  local date/time.
- Assets, liabilities, and liquid-assets metric cards.
- Static net-worth trend line, allocation bars, recent activity empty state,
  and accounts-to-review preview.
- Values are formatted through the display-only exact-decimal formatter.

### Settings

Settings auto-save to `<os.UserConfigDir>/Nestworth/settings.json` after a
valid selection. The file uses schema version `1`, mode `0600`, same-directory
temporary storage, `Sync`, and atomic rename. A corrupt, unsupported, or
unreadable file falls back to defaults; a save failure leaves the active
session preference in effect and shows a non-blocking warning.

The default profile is:

| Preference | Default |
| --- | --- |
| Appearance | System |
| Accent | Nestworth |
| Language | System |
| Timezone | System timezone |
| First day of week | Monday |
| Date format | `YYYY-MM-DD` |
| Time format | 24-hour |
| Display currency | CNY |
| Decimal separator | `.` |
| Grouping separator | `,` |
| Decimal places | 2 |

Available choices include:

- Appearance: System, Light, Dark.
- Accent: Nestworth, Ocean, Forest, Amber, Rose.
- Language: System, English, 简体中文, 正體中文.
- Timezone: System or a valid IANA timezone, with common zones offered in the
  editor and arbitrary IANA values accepted when submitted.
- Week start: Monday or Sunday.
- Date: ISO, day-first, month-first, or localized.
- Time: 24-hour or 12-hour.
- Display currency: CNY, USD, SGD, EUR, JPY, HKD, TWD, GBP, or AUD.
- Numbers: dot/comma decimal separator; comma/dot/space/apostrophe/no grouping;
  0, 2, or 4 decimal places.

The display currency is intentionally not the future Household base currency.
It changes presentation only and does not convert or mutate financial facts.

### Localization and appearance

The catalog has complete keys for English, Simplified Chinese, and Traditional
Chinese. The Traditional Chinese language option is labelled `正體中文`.
System locale resolution maps `zh-TW`, `zh-HK`, and `zh-MO` to Traditional
Chinese; other `zh-*` locales map to Simplified Chinese; unknown locales fall
back to English.

Appearance changes apply immediately. The accent palette is shared by primary
controls, badges, cards, trend lines, and allocation bars. System mode delegates
light/dark surfaces to the OS system variant.

## Explicitly deferred

This MVP does not include onboarding, financial entities, SQLite migrations,
account editing, activity posting, historical valuation, live providers, FX
calculation, authoritative charts, import/export, backup/restore, sync, or
notifications. Those capabilities require future active Go release contracts;
the inherited Rust/Tauri documents in the unreviewed archive are reference
material only and must not be implied by this UI milestone.

## Verification

The MVP contract is covered by tests for settings round trips and corrupt-file
fallback, supported currencies and separator validation, localization key
completeness and system mapping, exact decimal rounding, timezone/date-time
formatting, accent palettes, appearance mode, and UI page transitions.

The repository gate is:

```bash
gofmt -l cmd internal
go test ./...
go vet ./...
go build ./cmd/nestworth
git diff --check
```

macOS packaging remains unsigned and is verified separately by
`scripts/package-macos.sh`, which produces `Nestworth.app` and an arm64 DMG
using the migrated Nestworth icon resources.
