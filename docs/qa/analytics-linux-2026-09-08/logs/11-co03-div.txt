CO-03 Dividend Contribution — root cause + verification
=======================================================
When: 2026-09-09 (SGT)
DB: /tmp/nestworth-co03.db (copy of nestworth-analytics-qa/data/nestworth.db; no reseed)
Seed: CashDividendInput +12.50 USD on AAPL holding, local date 2026-08-28 (already in DB)

## Symptom
- Categories Dividend & Interest: +A$18.8325
- Contribution returnType=dividend_interest: 0 rows (API available=true) → UI empty

## Root cause (product, not seed)
`listActivitiesUntilQuery` in activity_repository.go (AnalysisService.loadInputs path)
only called attachActivityEffects and skipped hydrateActivities.

- activity.DividendDetail was nil for cash_dividend
- assetBucketFor(kind==cash_dividend) still tagged BucketDividendInterest on cash → Categories OK
- returnAssociation requires DividendDetail != nil → no ReturnDividendInterest on holding
- Contribution projectDividendContribution → rows=0

Seed CashDividendInput + activity_dividend_details were already correct. No seed change.

## Fix applied (product)
listActivitiesUntilQuery now calls hydrateActivities (same as ListActivities).
