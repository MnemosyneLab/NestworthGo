# macOS Simplified Pinyin in the AAPL quote form

Mac mini, macOS 27.2 arm64, Go 1.27.4. Both apps ran natively using their signed QA identities, `com.nestworth.gio` and `com.nestworth.dev`. Wails used its native WebView and Go host. App language was Simplified Chinese and the appearance was Light. The QA launcher checked both binary revisions, app identities and separate synthetic database and settings paths before launch.

Gio and Wails baseline `17c9deada`. Gio fix `ff7e52d1`. Wails Go was rebuilt at the baseline with the existing production frontend bundle from identical frontend source. Each 1280×800 and 900×600 run had its own copy of the same service-generated `Synthetic instrument performance` seed (`a6db2ec93bae284a0bd92a1c30a739613d129b577c52145fa8238f1f20685f9f`). Its only AAPL quote was a manual `1234.56789123 USD`.

In Gio, open Investment assets → All instruments → AAPL → Data records → Set price. In Wails, open Investment assets → All instruments → Edit AAPL → Set price. Focus the USD amount. Under the native Simplified Pinyin input source, send the letter keys `n i h a o`. The marked field shows underlined `ni hao`. Escape once cancels the marked text and keeps amount focus. In both baseline Gio sizes, the second Escape left the blank form open and the third closed it. Wails closed on the second Escape in both sizes.

Gio now lets the native handler remove the marked text and clears the empty marked range left by Gio 0.10.3. The first Escape still belongs to composition and the second closes. On both sizes, focus returned to Set price and Return reopened the form. Pressing Space during the next real composition committed the candidate `你好`; Escape then closed the form. After reopening, typing `203` with number keys enabled Save price, and Escape cancelled. The regular window also retained the typed `203` when Escape cancelled a subsequent composition on top of it. Wails cancelled both the committed candidate and the numeric draft and returned focus to the catalog container.

SQLite readback compared the AAPL quote identifier, exact amount, currency, source and times against the seed in all four profiles after the final cancel. All fields matched. No paste, AX value injection, or synthetic Gio event counted as IME evidence. The app-window originals show marked text and the selected candidate in the field. The OS candidate popup is outside the captured window.
