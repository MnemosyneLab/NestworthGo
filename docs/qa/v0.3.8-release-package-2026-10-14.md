```sh

GOCACHE=/tmp/nestworth-go-release-cache \
SDKROOT="$(xcrun --sdk macosx --show-sdk-path)" \
wails3 task package:release
```

The command ran with Node 22.20.0, pnpm 12.2.1 and Wails beta.28 on `PATH`.
It completed successfully: the skill reference checker passed 69 examples;
53 maintainer/installer tests passed; skill 1.9.0 was packaged; locked pnpm
dependencies were installed; Wails bindings were generated; frontend
TypeScript and Vite production build completed; Go release build completed;
the staging app was ad-hoc signed; DMG and ZIP were produced; and the package
verifier passed. Vite reported a large-bundle advisory; hdiutil emitted its
existing deprecation advisory. Neither failed packaging.

`build/windows/icon.ico` from the committed `build/appicon.png`, as declared by
the existing `generate:icons` task. Those generated working-tree outputs were
restored after packaging; no source changes were included in the release.

Non-interactive package checks then confirmed:

- Bundle ID `com.nestworth.app`, version `0.3.8`, build `9`, architecture `arm64`.
- `codesign --verify --deep --strict` passed for the staging app and both extracted archive payloads. `codesign -dv` reported `Signature=adhoc`; no Developer ID team identifier was present.

No app was launched. No real household database was opened or accessed. No

notarized.
