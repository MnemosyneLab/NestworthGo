## Package command and checks

With Node 24.22.0 and the versions above on PATH:

```sh
SDKROOT="$(xcrun --sdk macosx --show-sdk-path)" wails3 task package:release
```

The root task completed successfully:

- Skill references and 70 JSON examples matched current MCP tool names.
- 69 tool/installer tests passed in 216.995 seconds, including GNU and portable timeout paths.
- Skill 1.11.0 was packaged; pnpm dependencies were current; Wails bindings and the frontend TypeScript/Vite production bundle were generated.
- The native Go release build, ad-hoc app signing, DMG and metadata-preserving ZIP creation completed.
- The verifier checked bundle ID, app version/build, macOS minimum 27.0 in the plist and Mach-O load commands, arm64, native icon and strict signatures.
- The DMG was mounted read-only and the ZIP was tested/extracted. Key payload files in both archives matched the staging app.
- DMG/ZIP SHA256SUMS and the skill's adjacent checksum passed.
- Filename scans of the staging app, ZIP, read-only mounted DMG and skill archive found no database, SQLite, log, settings, environment or credential filenames. This does not claim an exhaustive content audit.
