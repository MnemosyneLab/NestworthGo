# Nestworth v0.3.7

**Unreleased release-note draft.** Candidate source metadata is v0.3.7 / build 8.
Publish only after all gates in the [release contract](v0.3.7.md) pass. The
latest published release remains v0.3.6. Nestworth skill 1.6.0 is versioned
separately from the App.

## What's new

- MCP can capture a consistent financial context, page through frozen detail,
  inspect a package item, compare two states, and link a coherent comparison to
  investment-change attribution. A difference between two states is not itself
  a return.
- MCP read tools show managed deposits and locked products, their actual
  operation history and household liquidity routes, with unknown values,
  reservations, fees and forecast evidence kept explicit.
- Dedicated guarded MCP plans can record completed managed-product lifecycle
  events, revise complete contract terms/policy, and record actual value
  observations for eligible locked products. These are financial writes and
  require `ledger_write`; renewal and reservation edits stay in the App.
- Historical analysis/trends now ensure actual snapshot coverage for the
  requested dates, diagnose sparse historical gaps, and resume bounded repairs
  safely when concurrent changes occur.
- Product table spacing is clearer on wide layouts and remains horizontally
  scrollable on narrow screens. Holding creation timestamps use consistent
  millisecond precision.

## For maintainers

Race CI preserves all tests and the race detector while splitting slow
application/MCP packages into bounded parallel shards. The race job fails if
any shard or test-name enumeration fails. PR #47 also bounds native dependency
installation and is included in current main. Its PR-head CI passed; see the
contract for the exact head and run.

## Before upgrading

Schema 15 remains the only supported database schema; no automatic migration is
added for schema 11 or other older schemas. Preserve the source database and
backup. JSON export is not a restorable backup. Managed product forecasts do
not post cash or income, and maturity does not automatically confirm receipt.

Install or update the optional skill separately using the
[user guide](../user/nestworth-skill.md). This does not connect MCP or change
permission mode. Scoped real Mac Codex/MCP/skill acceptance passed against
source SHA `2cad89e`; this is not native GUI or packaged-artifact acceptance.
Mac native GUI acceptance remains deferred to the user. Fresh Mac DMG/ZIP,
checksums, skill archive and isolated packaged-app smoke verification are also
required before publication.
The default package is ad-hoc signed; no current Developer ID signing or
notarization evidence is claimed.
