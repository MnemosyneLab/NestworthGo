# v0.3.2 Release Contract

## Status

`v0.3.2` / build `3` is the first public release, published on 2026-09-14
from the release commit on `main`. The GitHub release contains the local
macOS arm64 artifacts produced by the repository packaging task; the embedded
app is ad-hoc-signed for local launch, not Developer ID signed.

## Release goal

Carry forward the 0.3.1 desktop, backup/restore, CSV, and Analytics
capability while advancing the synchronized application identity to
v0.3.2 / build 3. This release also includes the current provider-neutral
market-data history, coverage, repair, and Data Health implementation.

## Included capability

- Wails v3 desktop shell with the Go backend and React/TypeScript frontend;
- local SQLite household, account, holdings, history, analytics, backup/restore,
  and CSV portability workflows;
- multi-currency valuation with explicit missing-data and incomplete-result
  semantics;
- unified Market Data and Data Health surfaces with historical coverage,
  repair planning, resumable snapshot rebuilds, and deterministic provider
  fixtures;
- Tiingo historical instrument data, Yahoo historical instrument data, and
  Frankfurter historical FX data, subject to provider credentials and network
  availability.

Historical provider breadth, live HTTP behavior, native desktop interaction,
and performance remain separately bounded acceptance gates below; their code
presence does not imply that those gates were exercised during publication.

## Acceptance checks

The release metadata must agree across the Go runtime, frontend package,
Wails configuration, platform manifests, and package artifacts:

~~~bash
GOCACHE=/tmp/nestworth-go-0.3.2 go test ./...
GOCACHE=/tmp/nestworth-go-0.3.2 go vet ./...
go build ./cmd/nestworth
cd frontend && pnpm run lint && pnpm run typecheck && pnpm run test
git diff --check
~~~

The packaging smoke target is:

~~~bash
wails3 task package:release
~~~

The resulting artifacts should identify as 0.3.2, build 3, and bundle
ID com.nestworth.app. Manual desktop smoke, accessibility review, signing,
notarization, and artifact retention remain separate gates.
