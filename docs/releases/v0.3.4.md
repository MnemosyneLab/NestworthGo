# v0.3.4 Release Contract

## Status

`v0.3.4` / build `5` is the unreleased development line, opened on 2026-09-19.
Portfolio and Holdings now share one page with Overview and Holdings tabs.
Holdings default to instrument summaries across accounts, with expandable account
rows, an account-detail view, and a zero-position filter. Native amounts are
aggregated by the backend; missing FX does not hide valid native values.
The current increment reorganizes Settings with section navigation, grouped
provider connections, separate diagnostics, and a shared preference save bar. Existing capabilities and schema `11` carry forward
from [v0.3.3](v0.3.3.md). No database migration is introduced by this change.

## Metadata

Go runtime, frontend package, Wails configuration, macOS plists and build
flags, Windows manifests/installer metadata, and Linux packaging identify
version `0.3.4`. Runtime and macOS build number is `5`.
Bundle identity remains `com.nestworth.app`.

Expected macOS outputs are `dist/macos/Nestworth.app`,
`Nestworth-0.3.4-arm64.dmg`, and `Nestworth-0.3.4-arm64.zip`.

## Validation boundary

Current cross-account holdings validation passed `go test ./...`, the full
frontend suite (52 files / 392 tests), lint, type checking, and production build.
Browser checks use an isolated local server and disposable household, not the
native desktop or real financial data. At 1000 x 640, grouped and account views,
zero-position filtering, keyboard expansion, preserved tab state, account
navigation, and table-contained horizontal overflow were verified. Creating a
position without a saved price was verified using the explicit unit-cost field;
the new position appeared automatically with cost available and price/gain missing.
Production packaging, native acceptance, live provider requests, signing, and
notarization have not been rerun for `0.3.4`.
The v0.3.3 release evidence remains historical and is not a v0.3.4 result.
