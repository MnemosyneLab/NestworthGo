## Released scope and compatibility

- Unified Tasks hub for upcoming actions, reviews and reconciliation, with
  audited reconciliation sessions and preserved nested-navigation context.
- Richer holding/instrument performance and daily investment reviews; improved
  historical overview, Available Funds, contribution filters and funding-gap
  attribution; shared financial/date formatting and rounding explanations.
- Financial fixes for realized gains, adjusted/transferred costs, blended cost,
  historical FX precision, overflow and preview freshness.
- Scoped historical/analysis loading and authenticated review reuse with full
  fallback. These do not establish whole-app or Mac startup performance claims.
- Wails beta.34 and the maintained first-party JSON codec wrapper.

**This is not a direct database upgrade from v0.3.8.** That release used
schema 16, which v0.3.9 rejects. Only verified schema 21 receives the additive
21→22 upgrade after a verified, flushed, read-only recovery copy is retained.
Schemas 20 and older, unversioned, malformed and future databases are blocked
before writable open. Backup inspection/restore accepts only verified 21/22
sources. Preserve originals and verified backups; never edit schema versions
to bypass validation. See [storage recovery](../architecture/data-and-ipc-contracts.md#database-support-and-storage-recovery).
