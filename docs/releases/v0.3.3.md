# v0.3.3 Release Contract

## Status

`v0.3.3` / build `4` is the current unreleased development line. The first
public release, `v0.3.2`, was published on 2026-09-14. Public publication of
this line is not implied by synchronized local metadata.

## Release goal

Carry forward the v0.3.2 local-first desktop and historical market-data
capability while making manual FX entry consistent with instrument creation.
The Market Data header owns the add action, and the form opens in a right-side
panel instead of occupying the main FX results area.

## Included capability

- Wails v3 desktop shell with the Go backend and React/TypeScript frontend;
- local SQLite household, account, holdings, history, analytics,
  backup/restore, and CSV portability workflows;
- explicit market-data refresh, historical coverage, repair planning, Data
  Health, and local quote history;
- manual FX observations saved without changing the preferred FX source;
- a Market Data header action and side-panel form for manual FX observations;
- synchronized application metadata: version `v0.3.3`, build `4`, and bundle
  ID `com.nestworth.app`.

## Metadata synchronization

The version and build must agree across the Go runtime, frontend package,
Wails configuration, macOS plists and Taskfile, Windows manifests and package
metadata, Linux package metadata, and release artifact names.

## Acceptance checks

Run from the repository root with the Xcode macOS SDK selected when required:

~~~bash
export SDKROOT="$(xcrun --sdk macosx --show-sdk-path)"
GOCACHE=/tmp/nestworth-go-0.3.3 go test ./...
GOCACHE=/tmp/nestworth-go-0.3.3 go test -race ./...
GOCACHE=/tmp/nestworth-go-0.3.3 go vet ./...
gofmt -l cmd internal
go build ./cmd/nestworth
cd frontend && pnpm run lint && pnpm run typecheck && pnpm run test && pnpm run build
git diff --check
~~~

The repository validation task is:

~~~bash
SDKROOT="$(xcrun --sdk macosx --show-sdk-path)" GOCACHE=/tmp/nestworth-go-0.3.3 wails3 task check
~~~

The packaging smoke target is:

~~~bash
SDKROOT="$(xcrun --sdk macosx --show-sdk-path)" GOCACHE=/tmp/nestworth-go-0.3.3 wails3 task package:release
~~~

The expected macOS artifacts identify as `0.3.3`, build `4`, arm64, and
`com.nestworth.app`, with the DMG named
`dist/macos/Nestworth-0.3.3-arm64.dmg`.
