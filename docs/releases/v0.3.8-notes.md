# Nestworth v0.3.8 — candidate, not published

Nestworth v0.3.8 (build 9) adds clearer upcoming actions, historical
comparisons and investment reviews, improves financial record reliability, and
expands local MCP workflows. The portable Nestworth skill is independently
versioned at 1.9.0. Package and acceptance status will be added only from
actual candidate evidence.

## What's new

- **Upcoming actions and home page.** See attention items and scheduled actions
  for today through the next 30 days, including receipt checks and
  source-specific reservation issues. The home page separates attention,
  upcoming items and investment reviews. Reads do not post receipts or refresh
  market data.
- **Historical Panorama.** Compare one date or two captured dates, inspect
  category/account changes and local price/FX evidence, explore bounded daily
  trends, and return from History without losing the comparison. Net-worth
  change explanations separate supported contributions from an explicit
  unexplained residual. Endpoint comparisons are not personal investment-return
  calculations; unsupported trading/quantity paths remain unexplained.
- **Accounts and investment labels.** Account composition groups by type or
  detail, with expandable top-ten views and complete source tables. Account
  lists/details show account-currency amounts first and household-currency
  amounts second, with partial/missing values explicit. Optional investment
  short names and compact saved-instrument selectors improve readability while
  preserving stable IDs and disambiguation.
- **Opt-in NAV investment reviews.** Eligible fund and bank-investment holdings
  can use actual dated unit-NAV evidence for low-return/loss review reminders.
  Pending reviews and setup are easier to find. Reviewed, temporarily ignored,
  permanently disabled and paused states remain distinct; 7/30-day ignore and
  resume controls preserve the underlying condition. Enrollment starts off.
  Estimates are unit-NAV changes, not personal return, selling advice, or
  monitoring while the app is closed.
- **Cash review and Repeat drafts.** Cash balance adjustments show an
  authoritative preview and require confirmation. Eligible ordinary cash
  activities can be repeated as a new draft, with exact amounts, source
  eligibility checks and safer in-session retry/confirmation recovery.
- **Broader MCP support.** Local clients can read upcoming actions, investment
  reviews and Historical Panorama, and use permission-checked review settings
  and ordinary Available Funds withdrawal-policy plans. New opt-in frozen
  management pages support server-side filters, stable sorting and complete
  continuation; product reservations can be paged separately. Bounded
  multi-target market reads, atomic instrument-metadata batches and review
  enrollment/snooze/acknowledgement batches include version checks and
  conservative recovery receipts. Existing legacy response shapes and
  financial-context disclosure choices are retained.

## Reliability improvements

- Corrected transferred-position cost boundaries, same-time ordering and exact
  persisted trade proceeds, plus liability/same-currency cash transfer previews
  and in-session Record/Fix retry identity.
- Kept delayed-NAV value estimates visible across day rollover with explicit
  quality labels and separately identified known subtotals. Available
  estimates do not become verified historical coverage or eligible returns.
- Product operation history loads bounded pages and obtains authoritative undo
  availability, including operations outside the current page.
- Improved historical civil-date/coverage handling and cancellation of obsolete
  queries; consolidated date controls, accessible tabs, focus behavior and
  archived History filter selections.
- Safely reclaim local backup replication metadata only after confirmed
  remote persistence and shutdown; aborted restores after quiescing remain
  write-fenced until restart.
- Reduced redundant product, reversal, upcoming-detail and reservation-source
  work. These are scoped improvements, not measured whole-app or Mac startup
  speedups.

## Important upgrade information

New databases use **schema 16**. A verified schema-15 database has one supported
additive upgrade: an empty investment short-name column. Before changing the
live database, the app retains and verifies a private, read-only pre-upgrade
recovery copy. Invalid schemas, schemas 1–14, unversioned databases and future
schemas remain blocked; there is no general migration chain.

Back up before upgrading and preserve original files. An old schema-15 app
cannot open the upgraded schema-16 database. Rollback uses a writable copy at a
new path of the retained pre-upgrade v15 database or a verified backup; never
modify its schema version or open the retained read-only original as the live
database. The recovery copy predates later financial writes. Validated v15/v16
backups are recognized, and restored v15 copies upgrade when normally opened.
JSON export is not a restorable backup and does not preserve short names.

Install/update the optional skill separately using the user guide. Installing
the skill does not install the app, connect an MCP client or grant permissions.
MCP remains local loopback; write modes retain their confirmation and recovery
constraints. Forecast interest is not posted income, maturity is not proof of
receipt, and unknown values are not zero.

## Package and acceptance status

This is an unpublished candidate. No v0.3.8 native package or acceptance
result is claimed. The current package flow targets Apple Silicon arm64 and
uses an ad-hoc signature, not Developer ID signing or notarization. Native
Mac GUI/VoiceOver and real external MCP-client acceptance have not yet been run
for this candidate. Earlier v0.3.7 acceptance does not cover these changes.
