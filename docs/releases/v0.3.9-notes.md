# Nestworth v0.3.9

Nestworth v0.3.9 (build 10) brings a unified Tasks hub, account reconciliation, richer investment reviews and historical analysis, and financial correctness fixes. The separately installed portable skill is version 1.11.0.

## Upgrade compatibility

- **Requires macOS 27.0 or newer on Apple Silicon (arm64).**
- **Only verified database schemas 21 and 22 are supported.** New databases use schema 22. A verified schema-21 database receives the additive 21→22 upgrade after a verified, flushed, read-only recovery copy is retained.
- **The schema-16 database used by v0.3.8 cannot be opened directly by this release.** Schemas 20 and older, unversioned, malformed and future databases are rejected before writable open. There is no general migration chain. Backup inspection/restore also accepts only verified schemas 21/22.
- Preserve original databases and verified backups before upgrading. Do not change a database's schema version manually. A retained read-only recovery copy must be copied to a new live path before opening; it predates subsequent financial writes.

## What's new

- **Unified Tasks hub.** Upcoming actions, investment reviews and reconciliation share one place, with clearer navigation and preserved reconciliation context when returning from nested pages.
- **Account reconciliation.** Review authoritative previews, reconcile account facts, and retain audited corrections and session progress.
- **Investment holdings and reviews.** Browse holdings by investment type, inspect instrument price/NAV performance separately from personal ledger returns, and use expanded daily investment review rules and explanations.
- **History and Available Funds.** Updated historical overview and liquidity views, contribution currency/class filters, clearer funding-gap attribution, and consistent manual-price and closed-day valuation handling.
- **More consistent financial presentation.** Shared money/date/plural formatting, clearer rounding explanations, holding-overflow handling, and navigation improvements.

## Reliability and performance

- Corrected historical realized gains, transferred/adjusted cost handling, blended cost, FX precision, and historical amounts outside the supported range.
- Market-data commits require a current successful sync preview. Edited settings and financial previews retain freshness checks and confirmation boundaries.
- Reduced repeated historical-series hydration, selected-account loading and analysis scans. Authenticated review reuse keeps full recomputation for invalid, missing or unsupported proofs. These are scoped optimizations, not measured whole-app or Mac startup claims.
- Updated Wails to v3.0.0-beta.34 and maintained first-party Go JSON encoding/decoding through the shared codec wrapper.
