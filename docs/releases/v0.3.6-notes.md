# Nestworth v0.3.6 (archived release-note draft)

This preserves the prepublication note draft. v0.3.6 was subsequently published
on 2026-10-03. The text below is retained for context and is not represented as
the exact GitHub Release body. Application v0.3.6 / build 7, business schema 15.

## What's new

- Optional continuous SQLite backup to Cloudflare R2 while Nestworth runs,
  remote-confirmed status and explicit recovery with preview, schema validation,
  confirmation and local safety copies. Restart and explicit re-enable after
  restore create a fresh isolated backup stream.
- Optional 30/90-day whole-stream history cleanup with preview and deletion
  acknowledgment. Cleanup protects the current stream, two verified sealed
  survivors, and unknown/unsealed/foreign streams. Backup and cleanup are off
  by default; cleanup does not bound storage for a long-running stream.
- Bundled bank logos, inherited account icons and broader generic/crypto icons.
- Fixes for financial forms and gain consistency, history-start default times,
  current-month empty states, recovery pagination, reservation recovery, pending
  account editing and annual-interest paid-through dates.
- Scoped performance improvements to cold analysis, latest account-value reads
  and repair-plan history reuse. These do not establish whole-app or Mac startup
  speedups; measurements and limitations are in the release contract.

## Before upgrading

Only schema-15 databases and validated schema-15 backups are supported. The
schema-11 database from v0.3.4 has no automatic migration. Preserve original
databases and backups; JSON export is not a restorable backup.

R2 backup is single-machine recovery, not multi-device bidirectional sync.
There is no backup daemon after app exit or cloud writer election. R2 credentials
are stored separately in a private local configuration database; existing
provider and AI/MCP settings remain included in business backups.

The default Apple Silicon Mac package is ad-hoc signed. Do not describe it as
Developer ID signed or notarized without fresh verification. Fresh DMG/ZIP,
checksums and standalone Nestworth skill bundle are required before publication.

Live R2 backup/recovery/retention and latest Mac GUI regression acceptance are
user-reported as passed. Automated baseline test/race CI passed at `f103cf4`;
final package and release-commit verification remain required. See the
[v0.3.6 release contract](https://github.com/MnemosyneLab/NestworthGo/blob/v0.3.6/docs/releases/v0.3.6.md) for evidence and packaging commands.
