# Gio and Wails capability and layout checklist

This is the Stage 1–6 checklist for the opt-in Gio preview. Implemented cells
describe runnable Gio behavior. Evidence cells link to the fixture and platform
records in the [roadmap](roadmap.md). Those records distinguish shared Go
comparison, Gio interaction tests, Linux X11, and native Mac interaction.
Each gap remains open until its workflow has implementation and verification.
The open capability column tracks implementation work. The
[Stage 6 exit gates](roadmap.md#stage-6-exit-gates) track the independent
interactive Wails and target-platform checks.
The [follow-up Linux acceptance](roadmap.md#follow-up-linux-acceptance)
records the reopened household name, Tasks tab navigation, missing quote
evidence and which analysis paths materialize SQLite snapshots.

Compare the Wails page title, navigation, section order, primary actions,
compact layout and feedback. A deliberate layout departure needs a reason and
its own evidence. Native Mac, VoiceOver and IME acceptance apply across the
in-scope pages. Earlier Mac runs cover the individual workflows named in the
roadmap.

Shared chart components landed through #286. Return, Asset and Wealth
History Trend use lines. Contribution uses signed bars, Change Drivers uses
a waterfall, and single-date Wealth History Allocation uses a donut or signed
bars.
Each integration has a keyboard-readable view of the underlying values.
Component Preview shows localized synthetic examples of every chart type,
including the shared Sankey flow diagram. Each additional chart integration
needs an accessible table and its own rendering, interaction and platform
evidence.

### Instrument catalog

Gio adds ordinary instruments with the shared catalog command. The form accepts
manual, provider and Agent quote sources. Provider lookup fills the selected
identity and denomination during creation. Existing denomination remains
read-only. The form exposes gold and silver templates, their holding unit, an
explicit reference-price preview, and advanced source and icon settings. Catalog
rows show the saved current quote, timestamp and provenance from the same query
used by Market Data. The initial compact form keeps identity fields visible and
places optional configuration under Instrument settings on edit. The native
comparison and the detailed metal-conversion evidence remain open.

### Instrument detail data
